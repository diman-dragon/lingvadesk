# Проверка вёрстки (текст всегда помещается)
Поднимает приложение в Chromium с подменённым мостом Capacitor (SQLite в Node, как в тестах), заливает данные с очень длинными названиями и переводами
и обходит все экраны (библиотека, учёба, режимы, игра, статистика и окна, настройки, формы) в списке и сетке, на экранах 360×640, 320×568, шрифт M и L.
`qa.py` ищет: выход за экран, горизонтальную прокрутку текста, обрезку родителем, карточки с прокруткой, страницы выше области.
Известные безопасные срабатывания: варианты ответа, прокрученные внутри `.opts` (offscreen-y), — это нормальная прокрутка.
Запуск: `tools/qa-layout/all.sh отчёт.txt` (из корня проекта). Настройки размеров экранов — `CONF` в `qa.py`.
