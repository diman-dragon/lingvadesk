# LingvaDesk

Офлайн-приложение для изучения языков на флешкартах. Android, Capacitor 6.2.0 + нативные Java-плагины.
Структура данных: **курс → колода → карточка**.

## Возможности
- Режимы: **обучение** (новые слова: знакомство → проверка), **последовательно**, **перемешать**, **повторение (SRS)**; позиция сохраняется для каждой пары «колода + режим»
- SRS — упрощённый SM-2 с оценками **Снова / Трудно / Хорошо / Легко** (Снова = повтор через 10 минут)
- Направления: язык → перевод и перевод → язык; примеры; озвучивание (Android TTS)
- Счётчики «к повторению» у языков, колод и в экране обучения («осталось N»), тап по карточке открывает ответ
- Полный CRUD по всей цепочке (курс, колода, карточка), перенос между курсами/колодами
- Библиотека списком или сеткой на всех уровнях; в обучении карточки листаются свайпом (← вперёд, → назад)
- Импорт/экспорт колоды `deck.json` (пример: `examples/deck.json`) через системные диалоги SAF
- Резервная копия `.fcbak` и восстановление БД с защитной копией и автооткатом
- Интерфейс: нижнее меню, экран «Сегодня», переворот карточки туда-обратно с анимацией, подпись интервалов под оценками, кнопка «Назад»
- Настройки: тема (системная / светлая «Бумага» / чёрная AMOLED), размер текста, анимации, направление, автоозвучка, сброс прогресса
- Нативный SQLite (Java), без storage-разрешений

## Сборка APK через GitHub Actions
1. Запушьте репозиторий в GitHub (содержимое папки `lingvadesk/` — в корень).
2. **Actions → Android build → последний запуск → Artifacts → `LingvaDesk-debug-apk`** (запускается на push, PR и вручную).
3. Установка **поверх** предыдущей версии, без удаления — см. `docs/UPDATES.md`.

CI: Node 22 → `npm install` → проверка архитектуры → тесты → JDK 17 → Gradle 8.2.1 → `cap sync` → `assembleDebug`.
Wrapper-jar не нужен: Gradle ставится в CI.

### Подписанный релиз (по желанию)
Создайте keystore один раз:
`keytool -genkeypair -v -keystore release.jks -alias lingvadesk -keyalg RSA -keysize 2048 -validity 10000`
и добавьте секреты в **Settings → Secrets and variables → Actions**:

| Secret | Значение |
|---|---|
| `KEYSTORE_BASE64` | `base64 -w0 release.jks` |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | `lingvadesk` |
| `KEY_PASSWORD` | пароль ключа |

Затем `git tag v1.0.0 && git push --tags` — CI соберёт подписанный APK и приложит к GitHub Release.
Храните keystore: без него обновления не встанут поверх установленной версии.

## Локальный запуск (VS Code / Android Studio)
Нужны Node 22+, JDK 17, Android Studio (SDK 34, эмулятор).
```bash
npm install
npm test               # SRS, импорт/экспорт, обучение, сквозной UI-сценарий, index.html
npm run check          # правила архитектуры
npx cap sync android   # копирует www/ в Android-проект
npx cap open android   # Android Studio → Run
```
Gradle wrapper создаст Android Studio; из консоли: `cd android && gradle wrapper --gradle-version 8.2.1`.
Логику интерфейса можно править в VS Code (`www/js`), Java-плагины — в `android/app/src/main/java`.
