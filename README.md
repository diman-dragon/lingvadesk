# LingvaDesk

Офлайн-приложение для изучения языков на флешкартах. Android, Capacitor 6.2.0 + нативные Java-плагины.
Структура данных: **проект → колода → карточка** (проект — язык, даты, что угодно).

## Возможности
- Структура **проект → колода → карточка** (проект — язык, даты, что угодно); полный CRUD на каждом уровне, перенос между проектами/колодами
- **Библиотека** (списком или сеткой): здесь живут все карточки; на самом верхнем уровне — **импорт и экспорт** всей библиотеки
- **Всё хранится в базе**: оценки, история, статистика, серии и лимиты читаются из неё же; под проверку произношения заложена таблица `pronunciations`
- Режим **«На слух»**: слово или фраза звучит, нужно перевести; «Показать текст» — подсказка
- Вкладка **Учёба** («Давай-ка поучим…»): режим (повторение / на слух) и список колод; **интервальное повторение считается по каждой колоде** (свои «повторить / новых / выучено», дневной лимит новых — на колоду), «Все колоды» собирает всё вместе
- **Без кнопок оценки**: расписание считается по поведению — свайпам, переворотам, времени на вспоминание и на ответе, возвратам назад
- Счётчик «сегодня», серия «дней подряд», статистика (удержание, повторения по дням), ↶ отмена последней оценки, лимиты новых карточек и размера сессии
- Проверка переворотом, выбором из 4 вариантов или вводом ответа; направление Я→П / П→Я / вперемешку; «пиявки»; итог сессии; правка карточки долгим нажатием
- Круглая кнопка озвучки с анимированным динамиком, вибрация, экран не гаснет во время учёбы; импорт и экспорт — в настройках
- **Свайпы по кругу**: карточки, страницы списков, экраны (Библиотека → Учёба → Настройки → Библиотека); переворот карточки туда-обратно
- **Без прокрутки**: экран всегда помещается, длинные списки — страницами; нижняя панель всегда на месте, настройки в шапке
- Системная «Назад» возвращает на шаг назад до библиотеки и дальше не выходит из приложения
- Резервная копия `.fcbak`, восстановление с защитной копией и откатом; озвучка голосом проекта; тема: системная / светлая «Бумага» / чёрная AMOLED
- Обновление поверх установленной версии, без удаления (`docs/UPDATES.md`)

## Сборка APK через GitHub Actions
1. Запушьте репозиторий в GitHub (содержимое папки `lingvadesk/` — в корень).
2. **Actions → Android build → последний запуск → Artifacts → `LingvaDesk-<версия>-debug` (внутри `LingvaDesk-<версия>-debug.apk`)** (запускается на push, PR и вручную).
3. Установка **поверх** предыдущей версии, без удаления — см. `docs/UPDATES.md`.

CI: Node 22 → `npm install` → проверка архитектуры → тесты → JDK 17 → Gradle 8.2.1 → `cap sync` → `assembleDebug`.
Wrapper-jar не нужен: Gradle ставится в CI.

### Подписанный релиз (по желанию)
Создайте keystore один раз:
`keytool -genkeypair -v -keystore release.jks -alias lingvadesk -keyalg RSA -keysize 2048 -validity 10000`
и добавьте секреты в **Settings → Secrets and variables → Actions**:

| Secret | Значение |
|---|---|
| `KEYSTORE_BASE64` | `base64 -w0 release.jks` |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | `lingvadesk` |
| `KEY_PASSWORD` | пароль ключа |

Затем `git tag v1.0.0 && git push --tags` — CI соберёт подписанный APK и приложит к GitHub Release.
Храните keystore: без него обновления не встанут поверх установленной версии.

## Локальный запуск (VS Code / Android Studio)
Нужны Node 22+, JDK 17, Android Studio (SDK 34, эмулятор).
```bash
npm install
npm test               # SRS, импорт/экспорт, обучение, сквозной UI-сценарий, index.html
npm run check          # правила архитектуры
npx cap sync android   # копирует www/ в Android-проект
npx cap open android   # Android Studio → Run
```
Gradle wrapper создаст Android Studio; из консоли: `cd android && gradle wrapper --gradle-version 8.2.1`.
Логику интерфейса можно править в VS Code (`www/js`), Java-плагины — в `android/app/src/main/java`.
