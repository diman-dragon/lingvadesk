# Обновление поверх установленной версии

Android ставит APK **поверх** установленного приложения (с сохранением всех данных) только если выполнены три условия:

| Условие | Как обеспечено в проекте |
|---|---|
| тот же `applicationId` | `com.example.lingocards` в `android/app/build.gradle` — **не менять** (имя приложения LingvaDesk — это только подпись) |
| та же подпись | постоянный ключ `android/app/lingvadesk-debug.keystore` лежит в репозитории; им подписаны все сборки CI. Свой ключ релиза — секреты `KEYSTORE_*` (см. README) |
| `versionCode` больше установленного | `версия × 1000 + номер запуска CI` (`1.1.0` → `10100xxx`); версия берётся из `package.json` |

Данные приложения (БД `lingocards.db`) хранятся под тем же именем, поэтому после обновления проекты, колоды, карточки и прогресс остаются.
Миграции схемы — в `DbHelper.onUpgrade` (версия БД `DbConfig.VER`); текущая версия схемы не менялась.

## Единоразово при переходе на 1.1.0
Прежние APK из CI подписывались случайным debug-ключом каждого запуска, поэтому Android не даст поставить 1.1.0 поверх них
(«Приложение не установлено»). **Один раз** сделайте резервную копию (Настройки → Резервная копия → Создать), удалите старую
версию, установите 1.1.0 и восстановите копию. Начиная с 1.1.0 все следующие версии ставятся поверх.

## Правила
- Версию поднимать при каждой правке: `package.json`, `www/js/constants/APP_VERSION.js`, верхняя запись `CHANGELOG.md`
  (`npm test` проверяет совпадение).
- Если позже перейти на собственный ключ релиза (секреты `KEYSTORE_*`), установки, подписанные постоянным ключом, нужно один раз переустановить.
- Не используйте имя ветки как версию: версию задаёт только `package.json`.
