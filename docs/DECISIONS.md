# Объединение двух версий проекта

Объединены: **LingoCards** (Flutter, `lib/*.dart`) и проект на **Capacitor** (язык → колода → карточка, SAF, backup).
Ниже — что взято и как разрешены противоречия.

## Противоречия и решения
| Тема | LingoCards (Flutter) | Capacitor-версия | Решение |
|---|---|---|---|
| Платформа | Flutter, Riverpod, sqflite, flutter_tts | Capacitor 6.2.0, Java-плагины, SQLite, SAF | **Capacitor 6.2.0** (исходное требование: нативные плагины, SAF, `.fcbak`). Flutter-код не переносился — его функции реализованы заново |
| Иерархия | плоская: колода имеет строку `lang` | язык → колода → карточка | **язык → колода → карточка**; код озвучки хранится у языка и наследуется колодами |
| Оценки SRS | Снова / Трудно / Хорошо / Легко, SM-2, Снова = +10 мин | 3 оценки, только дни | **LingoCards**: 4 оценки, формулы и тесты перенесены без изменений |
| Режимы | только SRS (очередь «к повторению») | последовательно, shuffle, SRS | **все три**; SRS-очередь строится заново каждую сессию |
| Оценка вне SRS | — | оценки обновляют SRS во всех режимах | **во всех режимах** (одна модель данных) |
| Порядок карточек | новые сверху (`id DESC`) | по `ord` | **по `ord`** — нужен для последовательного обучения и стабильного экспорта |
| Поле `example` | `NOT NULL` (пустая строка) | `NULL` | **NULL**; пустое значение не пишется в `deck.json` |
| Удаление | ручное удаление карточек и колод | `ON DELETE CASCADE` | **CASCADE** |
| Имя БД и пакет | `lingocards.db`, `com.example.lingocards` | `flashcards.db`, `com.example.flashcards` | **`lingocards.db`**, **`com.example.lingocards`** |
| Тема | Material 3, seed indigo, светлая/тёмная по системе | системная/светлая/тёмная | индиговая палитра + переключатель темы |
| `android/` в git | генерируется `flutter create`, игнорируется | содержит свои Java-плагины | **коммитится** (кроме build-артефактов) |
| CI | analyze + test + debug APK | проверка архитектуры + debug/release APK | **объединён**: проверка, тесты, debug APK (`debug-apk`), подписанный релиз по тегу |
| Формат файла колоды | — | `flashcards-deck` v1 | оставлен (нейтральное имя формата, не зависит от названия приложения) |

## Перенесено из LingoCards
(с 1.2.3 оценка выводится из поведения, кнопок нет — см. CHANGELOG) 4 оценки и алгоритм SM-2 (`srs/nextSrs`, `nextInterval`, `nextEase`), повтор «Снова» в конце текущей очереди,
тесты SRS (`test/nextSrs.test.js`), счётчики «к повторению / всего», «осталось N», сообщение «На сегодня всё! 🎉»,
тап по карточке для показа ответа, остановка озвучки при выходе из обучения, запрос TTS_SERVICE в манифесте,
индиговая тема, README-инструкции для VS Code, `extensions.json`, CI-шаги с тестами.

## Перенесено из Capacitor-версии
Иерархия язык → колода → карточка, SAF-импорт/экспорт `deck.json`, `.fcbak` с защитной копией и откатом,
сохранение позиции, shuffle, направления, архитектура «один файл — одна функция».
