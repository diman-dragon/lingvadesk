# История версий

Версия повышается при каждом изменении: `package.json`, `www/js/constants/APP_VERSION.js` и значение по умолчанию в
`android/app/build.gradle` меняются вместе (это проверяет `test/version.test.js`). В CI версия берётся из тега `vX.Y.Z`.

## 1.2.0
- Полная реорганизация. Верхний уровень — **Проект** (язык, даты — что угодно) → Колода → Карточка; полный CRUD на каждом уровне
- Карточки живут только в библиотеке. Импорт и экспорт — на самом верхнем уровне библиотеки: экспорт всей библиотеки одним файлом, импорт одной колоды или всей библиотеки (без дублей)
- Отдельная вкладка **Учёба**: область (вся библиотека / проект / колода), статистика и три режима — интервальное повторение, обучение (знакомство → проверка), простое повторение (все карточки по кругу, по порядку или вперемешку)
- Свайпы по кругу: карточки листаются по кругу в обе стороны; страницы списков и настроек — по кругу; за краем верхнеуровневого экрана — следующий экран (Библиотека → Учёба → Настройки → Библиотека)
- Никакой прокрутки: экран всегда помещается; длинные списки разбиты на страницы по высоте экрана, настройки — четыре страницы
- Системная «Назад» возвращает на шаг назад каждый раз до библиотеки и дальше не выходит из приложения
- Нижняя панель всегда на месте (включая учёбу и формы); настройки перенесены в шапку
- Позиции сессий хранятся по области и режиму; данные существующих установок сохраняются, обновление ставится поверх

## 1.1.1
- Полная пересборка архива проекта: все файлы 1.1.0 в одном комплекте, документация и тесты синхронизированы с кодом
- Проверки перед выпуском: архитектура (`npm run check`), 50 тестов (`npm test`), сквозной прогон интерфейса в браузере (формы, сетка, история «Назад», свайпы)

## 1.1.0
- Приложение называется **LingvaDesk**; в иконку и интерфейс внедрён знак DataLaw (векторная копия логотипа в `assets/brand`)
- Структура: **Проект → Колода → Карточка** (раньше «Язык»); данные существующих установок сохраняются
- Полный CRUD по всей цепочке: создать / открыть / изменить / удалить курс, колоду и карточку; перенос колоды в другой курс и карточки в другую колоду; «Сохранить и добавить ещё»
- Библиотека на всех уровнях (курсы, колоды, карточки) — списком или сеткой; переключатель в шапке и в настройках
- Жесты в обучении: свайп влево — вперёд, вправо — назад; карточка следует за пальцем, улетает и возвращается с анимацией
- Обновление поверх установленного: постоянный ключ подписи, тот же applicationId, versionCode растёт вместе с версией (см. `docs/UPDATES.md`)
- Версия берётся из `package.json` (раньше в сборке попадало имя ветки)

## 1.0.1
- Режим «Обучение»: пачка из 10 новых слов — знакомство (обе стороны, пример, озвучка), затем проверка с оценками
- Карточку можно переворачивать туда и обратно сколько угодно раз; оценки доступны после первого открытия ответа
- Новая палитра: светлая «Бумага» (тёплая бумага + бирюза) и чёрная AMOLED (мятный неон)
- Иконка приложения: адаптивная, с монохромным слоем для тем Android 13+
- Версия приложения показывается в «Настройках → О приложении»
